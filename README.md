
# TradeMap — Геоинформационная система поддержки решений в ритейле

Интерактивная карта и аналитическая платформа для анализа существующих ТЦ и выявления перспективных локаций для размещения новых объектов.

Система использует данные OpenStreetMap и алгоритмы пространственного анализа, включая диаграммы Вороного, моделирование зон влияния, учёт пространственных барьеров и оценку интенсивности конкуренции. Результаты помогают анализировать территориальное распределение ТЦ и обосновывать решения о развитии торговой сети.

## Возможности

- **Карта объектов** — отображение ТЦ с фильтрацией по районам Волгограда.
- **Полигоны Вороного** — расчёт зон влияния ТЦ с учётом границ территории и пространственных барьеров.
- **Пространственные барьеры** — визуализация рек, парков и других препятствий.
- **Зоны влияния** — анализ территориального охвата существующих ТЦ.
- **Аналитическая сетка** — разбиение территории на ячейки для пространственного анализа.
- **Интенсивность конкуренции** — визуализация распределения конкурентной нагрузки.
- **Добавление потенциальных ТЦ** — моделирование сценариев размещения новых объектов.
- **Расчёт маршрутов** — построение маршрутов между выбранными точками.
- **Аналитика спроса** — дашборд для анализа и сегментации территории.

### Установка и запуск

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/Lyubov15/shopping_malls.git
   ```

2. Перейдите в каталог проекта:

   ```bash
   cd shopping_malls
   ```

3. Установите зависимости бэкенда:

   ```bash
   cd Backend
   npm install
   ```

4. Запустите сервер:

   ```bash
   npm start
   ```

5. Откройте приложение в браузере. Сервер будет запущен на порту 3000 и раздавать соответствующие HTML-файлы.
